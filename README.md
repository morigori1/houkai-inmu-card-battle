# 崩壊淫夢カードバトル

元は Cursor Canvas で作成された単一ファイルの React ゲームを、独立した Web アプリケーションに変換したものです。

## ゲーム概要

田所浩二を中心とした淫夢ファミリーによるカードバトルゲーム。語録カードで戦い、崩壊イベントを乗り越えて敵を倒そう。

### 特徴

- **カードバトルシステム**: 攻撃・防御・回復・ネタ・混沌の5種類のカード
- **熱量システム**: 戦闘中に熱量を溜めて強力な技を発動
- **崩壊イベント**: ランダムに発生する世界観的な危機イベント
- **ステージ制**: 複数のステージと複数章で展開するストーリー
- **効果音**: Web Audio API による合成効果音（外部ファイル不要）

## 実行方法

### 開発サーバー

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてプレイできます。

### プロダクションビルド

```bash
npm run build
```

`dist/` ディレクトリにビルド済みファイルが生成されます。

### プレビュー

```bash
npm run preview
```

## 技術スタック

- **フレームワーク**: Vite + React + TypeScript
- **スタイリング**: インライン CSS（テーマ変数使用）
- **画像**: Base64 data URI（オフライン動作可能）
- **効果音**: Web Audio API による合成

## 操作方法

### キーボードショートカット（バトル中）

- **1～9**: 対応する手札を選択・出す
- **Enter / Space**: ターン終了（パス）
- **M**: ミュート切り替え
- **Esc**: カード選択解除

### 進行状況

クリアしたステージは localStorage に自動保存され、章選択画面で✓マークが表示されます。何度でも再挑戦可能です。
