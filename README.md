# 崩壊淫夢カードバトル

淫夢語録をベースにしたカードバトルゲーム。野獣先輩や遠野などのキャラクターカードを使って田所浩二と戦います。

## 🎮 遊び方

### 基本ルール
- **目的**: 相手のHPを0にする
- **エネルギー**: カードをプレイするために必要。ターン開始時に回復
- **SAN値**: 正気度。一部のカードで増加
- **熱量**: 興奮度。一部のカードやコンボで増加

### 操作方法

#### マウス/タッチ
- カードをクリック/タップしてプレイ
- 「ターン終了」ボタンでターンを終了

#### キーボードショートカット
- `1-9`: 対応する位置のカードをプレイ
- `E`: ターン終了

### コンボシステム
特定のカード組み合わせで発動！
- **「野獣と遠野」**: 野獣先輩 + 遠野 → 熱量+20
- **「四章」**: MUR + KMR → SAN+15

## 📝 制約
- バックエンド不要のフロントエンドオンリー
- 淫夢ファンワークのトーンを維持
- 適切なコンテンツ（AV静止画等は含まない）

## 🎲 戦略のヒント
- 序盤は低コストカードで攻撃
- 中盤でコンボを狙う
- HPが低い時は回復カードを確保
- エネルギーは毎ターン増加（上限10）
- コンボで追加効果を狙え！
